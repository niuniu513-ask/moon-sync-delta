## 受控合成实验

Python 使用固定种子的伪随机字节，旧数据为 65,536 字节，块大小 512 字节。
每次签名帧为 8,788 字节。下面的总字节数包括一次签名传输和一次差量传输。

| 更新类型 | 新数据字节 | 差量帧字节 | 两帧合计 | 重建结果 |
|---|---:|---:|---:|---|
| 前部插入 10 字节 | 65,546 | 172 | 8,960 | 完全一致 |
| 替换 32 字节 | 65,536 | 683 | 9,471 | 完全一致 |
| 追加 352 字节 | 65,888 | 514 | 9,302 | 完全一致 |
| 清空内容 | 0 | 148 | 8,936 | 完全一致，应选择全量/清空指令 |
| 两半重排 | 65,536 | 166 | 8,954 | 完全一致 |
| 全部改变 | 65,536 | 65,689 | 74,477 | 完全一致，应选择全量 |

这是相对于未压缩完整文件大小的协议字节比较，不包含 HTTP/TLS 等传输封装。
没有与 rsync、CDC 或 VCDIFF 做同条件性能对照，没有使用真实用户备份，不代表吞吐性能、
实际网络成本或生产可靠性。小文件和整体变化数据确实可能增加流量。

## 2026-10-12 功能与验证增量

新增签名帧成本接口 `Signature::wire_size`、差量版本元数据与 `Delta::matches_basis`，
可在编码前估算传输成本并核对接收方版本。新增 `verify_delta` 对重建字节序列做完整摘要
验证，不分配重建结果；基底与差量仍需在内存中，不宣称流式文件处理。
文件命令 `inspect` 识别签名与差量并显示版本摘要；`verify OLD DELTA` 只读验证，不写结果。

核心测试现为 23 项，四后端共 92 次执行通过。独立 Python oracle 保留原六个合成场景，
新增六组空基底、清空、单字节块、短尾块、大块和二进制数据；核对只读验证不创建文件、
源与输出同路径不损坏输入、非法块参数、目录/缺失输入、错误签名与错误命令。
每组成功重建均与独立字节解释及 Python hashlib 校验一致。

CI 扩展为 Linux/Windows 矩阵，固定 Node.js 22 和 Python 3.12，记录实际工具链版本。
